> **本書の核となる方針**（まえがきより）:
> あらゆる変換回路を「エネルギーをどう蓄え、どう放出するか」という**1つの見方で貫く**。
> 降圧チョッパも絶縁型コンバータもインバータも「どこに蓄え、いつ放出するか」の違いにすぎず、回路ごとの暗記は要らない。
> また、解析がどんな**仮定（理想スイッチ・定常状態・小リプル）**の上に成り立つかを毎回明示する。
